## 🚀 Featured Projects

- **FoodRush Ecosystem** ([Live Demo](https://food-rush-web.vercel.app) | [Backend](https://github.com/theusinhoiost/FoodRush-Backend) | [Frontend](https://github.com/theusinhoiost/FoodRush-Web)): Event-driven food delivery platform powered by Java 25, Spring Boot 4.1, RabbitMQ (Topic Exchanges & DLQ), Redis 7, PostgreSQL 17, Flyway, Nginx Gateway, Prometheus/Grafana, and an Angular 22 SSR frontend with a Kitchen Display System (KDS).
- **BearDelivery SaaS** ([Live Demo](https://likedeliveryapp.vercel.app/) | [Repository](https://github.com/Bear-System-Brasil/Bear-delivery-app-web)): Production multi-restaurant delivery SaaS built with Next.js 15, React 19, TanStack Query, Zustand, Socket.IO, Vitest (2,020+ unit tests), and Playwright E2E.
- **PetTracker SaaS** ([Live Demo](https://pet-tracker-web.vercel.app/) | [Backend](https://github.com/theusinhoiost/Pet-Tracker-Backend) | [Frontend](https://github.com/theusinhoiost/Pet-Tracker-Web)): Pet healthcare and telemetry platform built with NestJS 11, Next.js 16, PostgreSQL, Google OAuth 2.0, JWT rotation, AWS S3 pre-signed URLs, automated daily vaccine cron jobs, Prometheus/Grafana Cloud, and GitHub Actions CI/CD.
